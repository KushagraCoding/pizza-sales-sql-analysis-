#**🍕 Pizza Sales Dashboard using SQL**

Welcome to the **Pizza Sales Dashboard SQL project! This repository showcases how to extract meaningful insights from raw pizza sales data using PostgreSQL**. 
From calculating total revenue to identifying top-performing pizzas, this analysis reveals valuable business insights.

## 📌 Project Objective

To analyze pizza sales data and:
- Understand sales trends
- Track customer preferences
- Improve operational performance
- Assist in strategic decision-making

## 🧠 Key SQL Insights

## 🔹 Basic Analysis
- Total number of orders
- Total revenue generated
- Highest-priced pizza
- Most common pizza size
- Top 5 most ordered pizza types

### 🔹 Intermediate Analysis
- Quantity per pizza category
- Orders distribution by hour
- Category-wise pizza distribution
- Top 3 pizzas by revenue
- Daily average pizza orders

### 🔹 Advanced Analysis
- % contribution of each pizza to revenue
- Cumulative revenue over time
- Top 3 pizzas by revenue per category

## 🛠 Tools Used
- PostgreSQL
- SQL Queries
- Power BI (for dashboard visualization - optional)


## 🧾 Database Schema

The analysis is built using the following three main tables:

- `orders`: contains order ID, date, and time
- `order_details`: contains pizza ID, order ID, and quantity
- `pizzas`: contains price, pizza size, and pizza type

## 📈 Key Metrics Created
- Total Revenue
- Total Number of Orders
- Average Order Value
- Total Pizzas Sold
- Average Pizzas per Order
